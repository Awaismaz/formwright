## 1. Verdict

The Studio looks like a real CAD product. The ribbon, PropertyManagers, sketcher, viewer, section, measure, revisions,
change notices and handoff pack are all there, and the agent's answers are good engineering. Assumptions are labelled, it
checks volumes by hand calculation, and the agent's progress never exposes its internals. But a paying SOLIDWORKS user
would hit three trust-breaking problems in the first 30 minutes:

- **Picking one edge for a fillet rounds three.** Every straight-edge fillet or chamfer is resolved at the edge's end
  vertex instead of its middle.
- **One click on the "suppress" eye can delete a feature.** A Delete button slides under the cursor on hover, with no
  confirmation and no Ctrl+Z.
- **Hand-made features break the parametric promise.** One manual fillet blocks any later parameter change ("ValueError: …
  no edges found at the picked locations").

Add raw Python errors, a Source tab that shows the Python script, holes that can't be dimensioned, a ribbon that hides
commands at common screen widths, and a token estimate six times too low. The result is a product that demos well but
isn't yet safe for daily use. The fixes are mostly small and well-contained (S/M). Do the P0s before any further feature work.

Speed: manual features rebuild in 0.2–0.7 s on a warm worker (excellent, and the toast shows the time). But the first
build in a fresh project took 15 s. A failing fillet took 14.5 s. Agent edits took 35–100 s with only "Working…" shown.

## 3. IDEAs (distinctive, not clutter)

1. **Repair, don't block (rebuild-failure assistant).** When a parameter change or reorder breaks a feature, the edit is
   kept. The broken feature turns amber in the tree with a before/after ghost of the lost edge/face and three buttons:
   *Re-pick* (the old pick is highlighted), *Suppress*, *Ask the agent to repair* (one targeted, cheap prompt). SOLIDWORKS
   and Fusion only show a red X and a cryptic message, and nobody shows you visually what was lost. This isn't clutter
   because it replaces today's dead-end 422 (STU-03) rather than adding a panel.
2. **Agent fills the PropertyManager.** For small edits ("fillet these edges 3 mm", "add 4 × M6 holes 10 mm from the
   edges") the agent doesn't write code. It opens the real PM pre-filled with a preview, and the user presses OK. It takes
   seconds instead of 90 s, uses a fraction of the tokens, and the result is an editable manual feature. No competitor
   bridges chat and native features this way. It isn't clutter because it reuses the existing PMs and removes waiting.
3. **Fastener-aware Hole Wizard.** Pick a Toolbox bolt size, and the wizard makes the correct clearance/tapped/c'bore hole
   (ISO 273 class choice). It places holes by edge distance and immediately shows *edge distance ≥ 1.5 d*, washer
   footprint vs edges, and a "make bolt" link to the Assembly. The agent's answer to my question (`shots/a9-p2-done.png`)
   shows users want exactly this reasoning. Doing it deterministically, with no tokens, is unique. It isn't clutter
   because it *is* the missing Hole Wizard (STU-08).
4. **Live design budget while dragging a parameter.** Next to each slider, show the change in mass, the cost class
   (from the DFM module) and which checks would change, updated before the rebuild finishes. Engineers make trade-offs on
   sliders; no CAD tool shows mass/cost deltas live. It isn't clutter because it's a single line under the active slider only.
5. **Typed commands with no tokens.** Ctrl+K inside the Studio runs "fillet 3", "hole M6 x4 10 from edges",
   "view top" or "suppress pocket" deterministically on the current selection. It's faster than the ribbon and doesn't
   need the agent. Onshape and SOLIDWORKS have command search but no parameterised verbs. It isn't clutter because it
   reuses the existing command palette.

## 4. Keep / don't change

- **Change notice** (`shots/a7-03-change-notice.png` text): exact deltas ("Volume +196.3 mm³ (+2.03 %)"), CURRENT /
  SUPERSEDED stamp, copy and print, "not a manufacturing approval". Excellent and honest.
- **Revision 3D compare**: green/red added/removed with mm³ (`shots/a7-05-compare.png`). Keep it.
- **Section view** with a hatched cap, X/Y/Z and a numeric offset (`shots/a5-section.png`). **Measure** with B-rep hover
  chips ("Line 9.000 mm", "Planar face · 998.1 mm²").
- **Manual-feature speed and feedback**: optimistic tree, a "Rebuilding…" pill, and a toast with seconds (fillet 0.28 s,
  hole 0.72 s). The "Needs a solid first…" tooltips on disabled ribbon buttons.
- **Sketcher core**: solver plus the DOF badge ("Under defined · 3 DOF"), H/V relation glyphs, Smart Dimension value box
  focused and ready to type, and the open-profile message "Draw at least one closed profile (lines/arcs meeting
  end-to-end, or a circle)."
- **Rollback bar**, right-click menus, rename, and the plane preview outlines (mirror/plane PMs).
- **Params with limits and sliders** ("Edits rebuild without AI or tokens and are kept only if checks pass").
- **Agent behaviour**: plain progress steps (no internals), interpreted requirements and assumptions up front,
  "assumption, please verify" labels, hand-calculation volume checks (chamfer Δ 234.6 mm³ correct), and "Undo this change".
- **STEP import**: exact solid plus recognition in 3.9 s, an honest explanation text, and recognised hole groups in the
  tree. **Similar parts** (clickable, with reasons). **Shop handoff pack** card with SHA-256 manifest and its checklist.
- **Material list** with densities and the "verify with your supplier datasheet" note. The checks disclaimer
  ("geometric consistency … not strength, fit or manufacturability").
