## 1. Verdict

The engines underneath are good. The Engineering Advisor's working (equations, citations, every step) is better than
most commercial calculators, and all four of my hand checks matched. The DFM measurements are face-exact. The print
checks measure deviation against the exact surface. Drawings regenerate associatively, and the revision row describes
the change. As deliverables, though, the outputs are not yet something a professional would send to a shop or a
checker:
- **Drawings can be wrong.** Chained dimension values land in the wrong span, and CHK-12 still passes.
- **Drawings are incomplete.** Radii, chamfers and shoulder lengths are missing, and raw parameter names such as
  `CH, PL, PR` are printed instead.
- **Drawings are poorly composed.** A 150 mm shaft is drawn vertically at 1:5 on A4.
- **Drawings cannot be edited at all.**
- **Signed calculations stay "Verified" after the model they checked has changed.**
- **"Verified calculation" means different things in different modules.** It needs a named engineer's sign-off in the
  Engineering Advisor, but every automatic mesh check in 3D Print Prep carries it.

Across the four modules, the experience feels like four apps sharing a sidebar. They use four different header
patterns. The Make tab labels differ from the module names. The Studio never shows that a drawing, an analysis or a
signed set is now out of date. The round trip is read-only: advice cannot be acted on. For example, "add a
break-edges note" is advised, but the Drawing Studio cannot add notes. The biggest gap against what a paying user
expects is control and release. They need to correct the output, then freeze an issued revision that everything
downstream is checked against.

- **Beam, cantilever** (L 200 mm, b×h 20×10 mm, E 207 GPa, P 100 N at the tip):
  - I = 1666.7 mm⁴
  - M = 20 000 N·mm and σ = Mc/I = **60.0 MPa** (app: 60.0)
  - δ = PL³/(3EI) = **0.7729 mm** (app: 0.77295)
- **Pin shear** (Ø6, single shear, F 1000 N, Sy 640 MPa):
  - τ = 4F/(πd²) = **35.37 MPa** (app: 35.37)
  - Ssy = 0.577·Sy = 369.3 MPa, so n = **10.44** (app: 10.44)
- **Bolted joint** (M10 8.8, L 40 mm, two 10 mm steel layers, 0.75 of proof load):
  - At = **57.99 mm²**
  - Sp = 580 MPa (ISO 898-1, d ≤ 16), so Fi = **25 225 N** and T = 0.2·Fi·d = **50.45 N·m**
  - kb = **734 771 N/mm** (Ad = 78.54 mm², ld = 14 mm, lt = 6 mm)
  - km (Shigley 8-23) = **2.2976 MN/mm**, so C = **0.2423**
  - All match the app.

  - Se = 184.1 MPa by my factors; the app gives 184.5, using kb = (d/7.62)^-0.107 = 0.8806 versus 1.24·d^-0.107 = 0.8787. Both forms are Shigley's; the difference is rounding.

| ID | Idea | Why it is not clutter |
|---|---|---|
| IDEA-01 | **Release gate: "Issue Rev A".** One action freezes the model build, drawing PDF/DXF/STEP, DFM report, signed calculation package and print exports into the existing shop handoff pack, with a manifest hash. Every module then compares itself with the *issued* build and shows "Changes since Rev A" (fixes MAKE-02/08/15/16 with one concept). | It replaces four ad-hoc staleness behaviours with one rule users already understand from PLM. Competitors at this price point (Onshape, Fusion) have release workflows only in enterprise tiers, and none of them carry DFM and calculations in the release. |
| IDEA-02 | **Fix-it loop from findings.** Each DFM, print or failure-mode finding gets "Fix in Studio". Either a deterministic parameter edit (keyway ends R = KW/2, corner radius ≥ tool radius) or the design agent with the faces pre-selected and the finding as the prompt. Then the advisor re-runs and shows the delta ("1 critical → 0, cost −8 %"). | It turns advice into a one-click design change. That is the "AI-native" promise, not another panel. No DFM tool (Protolabs, Xometry, CADDi) edits your parametric model. |
| IDEA-03 | **Checker mode for drawings.** A second user opens the sheet with CHK-12, DFM and calculation status overlaid, pins redlines to dimension ids, and approves. Only a named approval replaces "NOT APPROVED FOR MANUFACTURE" with the approver's name and date. | It makes the existing honesty banner into a workflow that earns removal, and it reuses the sign-off machinery from the Engineering Advisor. Drawing checking is a real, paid, tedious job. |
| IDEA-04 | **Section-at-a-click for calculators.** Pick a plane or face in a 3D view inside the Engineering Advisor. The exact B-rep section gives A, I, c and J at that cut (and Kt hints from the nearest shoulder or keyway), which feed the shaft or beam calculator with provenance "section at z = 62 mm". | It removes the most error-prone step (hand-entering section properties). It uses geometry the product already has exactly, and generic calculators cannot do it. |
| IDEA-05 | **Tolerance and fit intent captured once.** In the Studio, tag a feature "bearing seat Ø20 k6" or "M6 clearance, medium". This flows to drawing callouts (spec-tagged), DFM tolerance cost, hole-standard checks (MAKE-12) and stack-ups. | It closes the biggest drawing gap (MAKE-06d) at the source, without inventing tolerances: the user states intent once and every module uses it. |

## 4. Keep / don't change
- **Drawing:**
  - exact HLR views (view extents equal the model within 0.01 mm);
  - hole callouts with qty and PCD ("6X Ø14 THRU / EQ SP ON PCD Ø120");
  - first/third-angle symbol;
  - associative regeneration with a human-readable change row ("Regenerated: L 120→140");
  - the spec/inferred idea *on screen*;
  - the CHK-12 concept and its side panel;
  - the honest NOT APPROVED banner and "never invents tolerances" stance;
  - fast generation (about 2 s warm);
  - byte-identical SVG determinism.
- **Manufacturing Advisor:**
  - face-exact findings with "Measured / Limit / Source / Suggested fix";
  - green face highlight in the viewer;
  - stale banner with Re-analyse;
  - shop profile with "assumed default shop" disclosure;
  - cost breakdown (material / machine / setup) with stated assumptions and a quantity curve;
  - process cons such as "Aluminium is a metal: polymer printing gives a form/fit prototype only".
- **Engineering Advisor:**
  - the working panel (each step with equation, substituted values, Shigley or ISO reference, result);
  - SF value *and* source required;
  - unit toggle;
  - content-hash sign-off with history and invalidation on edit;
  - the four-level legend;
  - validation-wording guard;
  - results match textbook values.
- **3D Print Prep:**
  - tessellation deviation measured against the exact surface;
  - export reload check ("same volume, millimetres");
  - 3MF with units;
  - per-orientation rotation shown explicitly;
  - "Not slicer-verified" disclosure on every screen;
  - live re-analysis on the current build.
- **All modules:** they open directly on the part from the Make tab with `?project=`, and none of the screens leaked agent internals (no file names, tools or model ids). The only internal-looking strings are parameter names on drawings (MAKE-05) and rule ids (MAKE-28).
